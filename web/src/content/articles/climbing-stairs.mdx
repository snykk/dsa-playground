## How Climbing Stairs works

A staircase has `n` steps and you may climb 1 or 2 at a time. Two climbs are different if their sequences of moves differ, so 1 + 2 and 2 + 1 are two ways to climb three stairs. Let `ways(i)` be the number of ways to reach stair `i`.

<Steps>
  <Step title="Think about the last move">
    You arrived at stair `i` with a 1-step from `i-1` or a 2-step from `i-2`. Those cases are disjoint and cover everything.
  </Step>
  <Step title="Add the cases">
    `ways(i) = ways(i-1) + ways(i-2)`. With allowed steps `s1, s2, ...` the sum runs over all of them: `ways(i) = sum of ways(i - s)` for every allowed `s <= i`.
  </Step>
  <Step title="Set the base case">
    `ways(0) = 1`: there is exactly one way to stand on the ground, which is to make no move. This is the value every function in this repository returns for `n = 0`.
  </Step>
  <Step title="Fill upward">
    Compute `ways(1), ways(2), ...` up to `n`. For steps 1 and 2 only the last two values are needed.
  </Step>
</Steps>

<Callout title="ways(0) = 1 is not a special case">
It is what makes the recurrence work: `ways(2) = ways(1) + ways(0) = 1 + 1 = 2` (1+1 and 2). Defining `ways(0) = 0` would give `ways(2) = 1`, which is wrong.
</Callout>

## Pseudocode

```text
climbingStairs(n):                      # steps 1 and 2, O(1) space
    if n < 0: error
    if n == 0: return 1
    if n <= 2: return n
    prev2 = 1; prev1 = 2                # ways(1), ways(2)
    for i = 3 to n:
        current = prev1 + prev2
        prev2 = prev1; prev1 = current
    return prev1

waysWithSteps(n, steps):                # Python: climbing_stairs_variable_steps
    dp[0] = 1
    for i = 1 to n:
        for s in steps:
            if i >= s: dp[i] = dp[i] + dp[i - s]
    return dp[n]
```

## Implementation

Python has five functions: naive recursion, memoization, tabulation, the two-variable loop and the version with arbitrary step sizes. C++ and Go have only the two-variable loop for steps 1 and 2. A negative `n` is an error in all three languages (Python `ValueError`, C++ `std::invalid_argument`, Go panic), and `ways(0)` is 1 everywhere.

<Equation label="Naive recursion" expr="T(n) = T(n-1) + T(n-2) + O(1)" result="Theta(1.618^n)" />

The answer itself is a Fibonacci number: `ways(n) = F(n + 1)`. That is why the count grows exponentially, and why the 64-bit C++ and Go versions are exact only up to `ways(91)`: `ways(90) = 4660046610375530309` is tested, but `ways(92) = F(93)` exceeds the signed 64-bit range. Python integers have no limit.

The repository counts **ordered** sequences: the outer loop is over stairs. If you swapped the loops (steps outside, stairs inside) you would count each multiset of steps once, as in the coin-change count of combinations.

## Applications

- **Counting paths.** Any problem that asks for the number of ways to reach a position using a fixed set of moves.
- **Tilings.** Tiling a 2 x n strip with dominoes follows the same recurrence.
- **Interview classic.** It is usually the first DP exercise, before House Robber and Coin Change.

## Common mistakes

<Callout tone="warning" title="Watch out for these">
- **Wrong base case.** `ways(0)` is 1, not 0. With 0, `ways(2)` comes out as 1.
- **Off-by-one against Fibonacci.** `ways(n) = F(n + 1)`, not `F(n)`.
- **Overflow.** In C++ and Go the 64-bit result is exact only up to n = 91.
- **Swapped loops.** Stairs outside and steps inside counts sequences; steps outside counts combinations.
- **Zero or negative steps.** The code assumes positive step sizes.
</Callout>

## Frequently asked questions

<Faq>
  <FaqItem question="Why is it the Fibonacci sequence?">
    Reaching stair `n` takes a 1-step from `n-1` or a 2-step from `n-2`, so `ways(n) = ways(n-1) + ways(n-2)`. With `ways(1) = 1` and `ways(2) = 2` this is the Fibonacci sequence shifted by one.
  </FaqItem>
  <FaqItem question="Does the order of the steps matter?">
    Yes in this problem: 1+2 and 2+1 are different ways, so `ways(3) = 3`. Counting only which steps are used, not the order, is a different DP.
  </FaqItem>
  <FaqItem question="What does ways(0) = 1 mean?">
    There is one way to climb zero stairs: do nothing. The recurrence relies on it.
  </FaqItem>
  <FaqItem question="How do I handle large n?">
    In Python nothing is needed. In C++ and Go, take the result modulo a number at every addition if the problem asks for it, or use a big-integer type. The repository versions do not.
  </FaqItem>
</Faq>
