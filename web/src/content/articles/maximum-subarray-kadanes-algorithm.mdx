## How Kadane's algorithm works

A subarray is a contiguous block. There are about n<sup>2</sup>/2 of them, but every one of them ends at some index. Let `cur[i]` be the best sum of a subarray **ending at** index `i`. Then the answer is the largest `cur[i]`.

<Steps>
  <Step title="Start with the first element">
    `cur = best = arr[0]`. Starting from the first element, not from 0, makes all-negative arrays work.
  </Step>
  <Step title="Extend or restart">
    For each next element: `cur[i] = max(arr[i], cur[i-1] + arr[i])`. A run that ends at `i` either extends the best run ending at `i-1`, or starts fresh at `i`. Extending helps exactly when `cur[i-1]` is positive.
  </Step>
  <Step title="Remember the best">
    After every element, `best = max(best, cur)`. For the window, `kadane_with_indices` records where the current run started and copies it when `best` improves.
  </Step>
  <Step title="Return the best sum">
    One pass, two numbers: no table is needed because `cur[i]` depends only on `cur[i-1]`.
  </Step>
</Steps>

<Callout title="Why dropping a negative prefix is safe">
If the best run ending at `i-1` has a negative sum, any run that extends it is beaten by the same run without that prefix. So a negative running sum is never worth keeping, and the algorithm can safely restart at the next element.
</Callout>

The window moves only when `best` strictly improves, so on ties the earliest window is reported. For `[2, -2, 2]` the result is `(2, 0, 0)`.

## Pseudocode

```text
kadane(arr):
    if arr is empty: return 0
    best = cur = arr[0]
    for i = 1 to n - 1:
        cur = max(arr[i], cur + arr[i])
        best = max(best, cur)
    return best

kadaneWithIndices(arr):                 # Python
    best = cur = arr[0]; start = end = temp = 0
    for i = 1 to n - 1:
        if cur < 0: cur = arr[i]; temp = i
        else:       cur = cur + arr[i]
        if cur > best: best = cur; start = temp; end = i
    return (best, start, end)
```

The two forms are equivalent: `max(arr[i], cur + arr[i])` restarts exactly when `cur < 0` (when `cur` is 0, both options are equal).

## Implementation

Python has three functions: `kadane_algorithm` (the sum), `kadane_with_indices` (sum and window) and `kadane_dp` (the same with an explicit O(n) table). C++ and Go implement only the sum. Every version treats an empty array as sum 0 (an empty-sum convention) while a non-empty array always yields a non-empty subarray, so an all-negative array returns its largest element. The C++ version sums in `int`, so a large input can overflow; Python integers are unbounded and Go's `int` is 64-bit.

## Applications

- **Finding the best stretch.** The most profitable contiguous period of daily gains and losses.
- **Signal and sequence analysis.** A maximum-scoring segment of a sequence of scores, such as in bioinformatics.
- **A building block.** The maximum-sum rectangle in a matrix, circular maximum subarray and many interview problems use it directly.

## Common mistakes

<Callout tone="warning" title="Watch out for these">
- **Starting `best` at 0.** That fails for all-negative arrays, where the answer is the largest element, not 0. The code starts from `arr[0]`.
- **Resetting to 0 instead of to `arr[i]`.** Setting `cur = 0` on a negative sum quietly allows an empty subarray.
- **Mixing up the empty subarray rule.** Decide whether an empty subarray is allowed; this changes the answer for negative arrays.
- **Overflow.** Sums of many large numbers overflow 32-bit integers.
- **Wrong indices.** The window start must be copied when `best` improves, not when `cur` restarts.
</Callout>

## Frequently asked questions

<Faq>
  <FaqItem question="What does Kadane's algorithm return for an all-negative array?">
    The largest (least negative) element, since the subarray must contain at least one element. `[-3, -1, -2]` gives `-1`, with the window `(1, 1)`.
  </FaqItem>
  <FaqItem question="Why does the code return 0 for an empty array?">
    There is no subarray, so the repository picks 0 as a convention. `kadane_with_indices` returns `(0, -1, -1)`, with -1 meaning no window.
  </FaqItem>
  <FaqItem question="Is Kadane's algorithm dynamic programming?">
    Yes. `cur[i] = max(arr[i], cur[i-1] + arr[i])` is a one-dimensional recurrence. Only the previous value is needed, so the table collapses to one variable, which is what `kadane_dp` shows explicitly.
  </FaqItem>
  <FaqItem question="How do I get the subarray itself?">
    Use `kadane_with_indices` in Python: it returns the sum, the start index and the end index. Slice with `arr[start:end + 1]`. The C++ and Go versions return only the sum.
  </FaqItem>
</Faq>
