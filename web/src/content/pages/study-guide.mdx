## How to use this guide

- Follow the phases in order, and inside a phase the lists and the order of their topics. Skip what you already know.
- Pick one language. Every topic has Python, C++ and Go code with tests; Python is gentle for a first pass and C++ is the usual choice for contests.
- Read the topic article first. Then read the code, close it, and write your own version; run the tests to check it.
- Solve a few practice problems per topic before you move on. Depth matters more than speed.
- The level next to each topic (Beginner, Intermediate, Advanced) comes from its article. Every topic has a visualization on its page, under See it in action.

## Learning tips

1. Implement before memorizing. Read an implementation, close it, and write your own from scratch.
2. Test edge cases: empty input, one element, duplicates, sorted and reversed input.
3. Learn when not to use a technique as well as when to use it. Each area overview has a section on choosing between its topics and a list of common mistakes.
4. Time yourself. If a Medium problem takes more than 30 minutes, review the pattern before you read the answer.
5. Revisit old topics. After dynamic programming, graph algorithms look different.

## Frequently asked questions

<Faq>
  <FaqItem question="Do I have to follow the phases in order?">
    No, but later phases build on earlier ones: graph algorithms reuse the Phase 2 structures, and dynamic programming builds on the patterns of Phase 3. If you already know a phase, check its milestone; if it holds, move on.
  </FaqItem>
  <FaqItem question="How long does it take?">
    About fifteen weeks to the end of Phase 4 at a steady pace. Phase 5 is open-ended: contest techniques improve with practice more than with reading.
  </FaqItem>
  <FaqItem question="Is every topic of the repository in the guide?">
    Yes, each exactly once. A topic that serves two phases sits where it is first needed; the priority queue, for example, waits for heaps in Phase 2.
  </FaqItem>
  <FaqItem question="What do the milestones refer to?">
    Problem difficulty on common practice sites: LeetCode Easy, Medium and Hard, and Codeforces Division 2. They are a rough guide to whether the phase has settled, not a requirement.
  </FaqItem>
</Faq>
