## The problem

Divide and conquer is a paradigm, not one problem. It fits problems that contain smaller instances of themselves. The recipe has three steps:

- **Divide.** Split the input into smaller subproblems of the same kind.
- **Conquer.** Solve each subproblem recursively. A subproblem small enough to answer directly ends the recursion.
- **Combine.** Build the answer to the whole problem from the answers to the parts.

Where the work happens separates the algorithms. Merge Sort splits cheaply and does its work when combining. Quick Sort does its work when dividing and combines for free. Binary Search discards all but one part, so it has nothing to combine. Strassen's algorithm saves work by making fewer recursive calls.

This folder has one topic of its own, Strassen's matrix multiplication. The other divide-and-conquer algorithms in the repository sit in the category of their problem, so the table below links to them.

## A worked example: where Strassen's saving comes from

Strassen's algorithm splits each `n x n` matrix into four blocks. The schoolbook rule for blocks needs eight block products, so `T(n) = 8T(n/2) + O(n^2)`, which solves to `O(n^3)`: no gain at all. Strassen's seven products give `T(n) = 7T(n/2) + O(n^2)`, which solves to `O(n^2.81)`. One recursive call fewer is enough to change the exponent.

The repository's Python code was run on random integer matrices, with the naive triple loop counted at the cutoff of `n <= 64`:

## Complexity

A divide-and-conquer recurrence has the form `T(n) = a T(n/b) + f(n)`: `a` subproblems of size `n/b`, plus `f(n)` work to divide and combine. Which term dominates decides the result:

<DataTable
  columns={['Case', 'What happens', 'Example', { label: 'Result', kind: 'mono' }]}
  rows={[
    ['Every level costs about the same', 'the work per level is n and there are log n levels', 'Merge Sort', 'O(n log n)'],
    ['The root dominates', 'the combine step costs more than all the smaller levels together', 'Randomized Quickselect (expected time)', 'O(n)'],
    ['The leaves dominate', 'the number of leaves, `a^(log_b n)`, outgrows the work per level', 'Strassen', 'O(n^(log2 7)) = O(n^2.81)'],
    ['One subproblem, constant work', 'the range shrinks by a factor of `b` each step', 'Binary Search', 'O(log n)'],
  ]}
/>

The recursion also costs memory. The depth of the recursion is `log n` when the parts are even, and Quick Sort's Python version keeps it that way by recursing into the smaller side first. Merge Sort adds O(n) for its temporary halves and Strassen adds O(n^2) for its block sums.

## Applications

- **Sorting and searching.** Merge Sort, Quick Sort and Binary Search.
- **Geometry.** Finding the closest pair of points.
- **Signal processing and polynomials.** The Fast Fourier Transform multiplies polynomials and convolves sequences.
- **Linear algebra.** Strassen's algorithm for large matrix products.

## Common mistakes

<Callout tone="warning" title="Watch out for these">
- **Missing or wrong base case.** Without a direct answer for the smallest parts, the recursion never ends.
- **Uneven splits.** Quick Sort with a bad pivot makes one part empty at every step and becomes O(n^2).
- **A combine step that is too slow.** Copying whole arrays at every level of the recursion can turn O(n log n) into something worse.
- **Using it when subproblems overlap.** Divide and conquer recomputes them. Use dynamic programming instead.
- **Ignoring the cutoff.** Recursing all the way down costs more than a direct method on small inputs, which is why Strassen's code here switches to the naive loop at `n <= 64`.
</Callout>

## Frequently asked questions

<Faq>
  <FaqItem question="How is divide and conquer different from dynamic programming?">
    Both split a problem into subproblems. Divide and conquer needs the subproblems to be independent, so each is solved once. Dynamic programming is for overlapping subproblems and stores the answers so that each is solved once.
  </FaqItem>
  <FaqItem question="Why does Strassen's algorithm use only seven products?">
    Strassen found seven products of sums and differences of blocks whose combinations give all four result blocks. Every cross term cancels, so the result equals the schoolbook value. That changes the recurrence from `8T(n/2)` to `7T(n/2)` and the exponent from 3 to about 2.81.
  </FaqItem>
  <FaqItem question="Which topics use divide and conquer?">
    Merge Sort, Quick Sort and Binary Search in sorting and searching, Closest Pair of Points in geometry, the Fast Fourier Transform in mathematical algorithms, and Strassen's algorithm here. The links under related lead to each.
  </FaqItem>
</Faq>
