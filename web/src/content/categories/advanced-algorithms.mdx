## What this area covers

The two sub-areas answer different questions and have almost nothing in common in code.

- **Backtracking** looks for a configuration that obeys a set of rules: queens that do not attack each other, a coloring with no clash on an edge, a filled Sudoku, a route through a maze. The cost is exponential in the worst case, and the work is in pruning.
- **Specialized techniques** answer a stream of queries on one fixed structure. They spend time once to split it and then answer each query by touching only a few pieces. The cost per query is O(sqrt n) or O(log n).

The only shared background is a depth-first search and some recursion. The tree techniques in the second area use DFS to compute sizes, and the maze in the first is a DFS on a grid.

## A path through the area

1. Read **Backtracking** first if the recursion pattern is new. Start with Rat in a Maze, then N-Queens, Graph Coloring and Sudoku.
2. Read **Specialized Techniques** from the array side. Square root decomposition comes first, Mo's algorithm second.
3. Then take the tree side: heavy-light decomposition, then centroid decomposition.

The two sub-areas are independent, so you can take either one first. Within each, the order in the lists above goes from the simplest topic to the hardest.

## Frequently asked questions

<Faq>
  <FaqItem question="Why are these two groups in one folder?">
    They are the two sets of techniques in the repository that go beyond the standard sorting, searching and graph topics, and they both rely on recursion and on cutting a problem into parts. Each has its own overview with the details.
  </FaqItem>
  <FaqItem question="Do I need Backtracking before Specialized Techniques?">
    No. The two sub-areas do not depend on each other. Specialized Techniques needs prefix sums for the array topics, and a depth-first search for the tree topics.
  </FaqItem>
  <FaqItem question="Which area is harder?">
    The backtracking topics are Beginner or Intermediate, and each is short. Specialized Techniques goes from Intermediate (square root decomposition) to Advanced (Mo's algorithm, heavy-light and centroid decomposition), because the ideas need more setup.
  </FaqItem>
</Faq>
