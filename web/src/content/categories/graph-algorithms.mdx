## The problem

A graph is a set of vertices joined by edges. The edges can be directed or undirected and weighted or not, and the Graph data structures section shows how to store them. This section asks questions about a stored graph, and each of the four areas asks a different kind of question:

- **Traversal:** which vertices can I reach from here, and in what order?
- **Shortest path:** what is the cheapest way from one vertex to another, or to all others?
- **Minimum spanning tree:** which edges connect every vertex for the smallest total weight?
- **Advanced graph:** does the graph have a valid order, hidden cycles of mutual reachability, single points of failure, or a limit on how much can flow through it?

Traversal comes first because the other three lean on it. BFS is the idea behind unweighted shortest paths, DFS behind topological order, components and bridges, and Dijkstra's priority queue is BFS with a cost.

## A path through the area

<Steps>
  <Step title="Learn to store a graph">
    Read the Graph data structures first: adjacency list, adjacency matrix and edge list. Every algorithm here takes one of them as input.
  </Step>
  <Step title="Traversal">
    BFS and DFS. They are short, and the rest of the section reuses both.
  </Step>
  <Step title="Shortest path">
    Start with Dijkstra's algorithm. Bellman-Ford, Floyd-Warshall and A* each change one of its assumptions: negative edges, all pairs, a single goal with a hint.
  </Step>
  <Step title="Minimum spanning tree">
    Kruskal and Prim solve the same problem from two directions. Kruskal also needs the union-find structure.
  </Step>
  <Step title="Advanced graph">
    Take topological sort first, then strongly connected components, bridges and 2-SAT, which reuse DFS. Network flow is the most self-contained part and can be read last.
  </Step>
</Steps>

## Applications

- **Maps and routing.** Shortest paths over road networks, with A* when there is a goal and a distance estimate.
- **Networks.** Spanning trees for cabling and for loop-free switching, bridges for single points of failure, flow for capacity planning.
- **Build systems and schedulers.** Topological order of tasks and detection of dependency cycles.
- **Social and web graphs.** Components, reachability and strongly connected groups of pages or people.
- **Constraint solving.** 2-SAT turns a set of pairwise constraints into a graph question.

## Common mistakes

<Callout tone="warning" title="Watch out for these">
- **Using BFS on a weighted graph.** BFS counts edges, not cost. It returns the fewest-hop path, which can be far more expensive than the cheapest one.
- **Feeding negative edges to Dijkstra.** It does not fail; it silently returns wrong distances. Use Bellman-Ford.
- **Treating a spanning tree as a shortest-path tree.** A minimum spanning tree minimises total weight, not the distance from any one vertex.
- **Forgetting that graphs can be disconnected.** One traversal from one start only covers one component, and Kruskal then returns a forest.
- **Running directed algorithms on undirected input, or the reverse.** Topological sort needs a DAG, SCC algorithms need directed edges, and bridges are defined for undirected graphs.
</Callout>

## Frequently asked questions

<Faq>
  <FaqItem question="Where do I start if I know nothing about graphs?">
    Read the Graph data structures, then BFS and DFS in Traversal. After those, any area can come next, but Shortest_Path is the usual choice because Dijkstra's algorithm is also the base of A* and a model for Prim.
  </FaqItem>
  <FaqItem question="Which one should I use for the cheapest path?">
    Dijkstra when all weights are non-negative and you need one source. Bellman-Ford when some are negative. Floyd-Warshall when you need every pair on a small graph. A* when there is a single goal and a heuristic that never overestimates.
  </FaqItem>
  <FaqItem question="How are Kruskal and Prim related to Dijkstra?">
    Prim and Dijkstra share a shape: both repeatedly take the cheapest candidate from a priority queue. The key differs. Dijkstra ranks a vertex by its total distance from the source, Prim by the weight of one edge into the tree, so they solve different problems.
  </FaqItem>
  <FaqItem question="Which algorithms use DFS underneath?">
    Topological sort in its DFS form, Kosaraju and Tarjan for strongly connected components, bridges and articulation points, and 2-SAT, which runs Tarjan on an implication graph. Ford-Fulkerson finds its augmenting paths with DFS in this repository, while Edmonds-Karp uses BFS.
  </FaqItem>
</Faq>
