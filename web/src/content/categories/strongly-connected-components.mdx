## The problem

In a directed graph, vertex `u` can reach `v` along edges without `v` being able to reach `u`. A **strongly connected component** (SCC) is a maximal set of vertices in which every vertex can reach every other. Every vertex belongs to exactly one SCC, and a vertex on no cycle is a component of its own.

If you shrink each component to one vertex, the result, called the condensation, has no cycles. That makes SCCs the standard way to turn a directed graph with cycles into a DAG, and the list of components comes out in a topological order of that DAG (Kosaraju) or in its reverse (Tarjan).

Both algorithms find the components with DFS and return the same sets of vertices. They differ in how they know where one component ends.

Both find the same two sets, `0, 1, 2` and `3, 4, 5`. Kosaraju reports the component with no incoming edge first. Tarjan reports the component with no outgoing edge first, so its list is the reverse. The order of the vertices inside a component also differs, and neither order is sorted. If you need a particular order, sort the result yourself.

## Applications

- **Condensation.** Collapse cycles to get a DAG, which you can then order or run dynamic programming on.
- **2-SAT.** A formula is unsatisfiable exactly when a variable and its negation share a component.
- **Dependency analysis.** Cyclic groups of modules or packages show up as components with more than one vertex.
- **Web and social graphs.** Groups of pages or people who can all reach each other.

## Common mistakes

<Callout tone="warning" title="Watch out for these">
- **Running either algorithm on an undirected graph.** Every connected component is then strongly connected, so a plain traversal does the job.
- **Assuming one output order.** Kosaraju and Tarjan return opposite orders of components, and code that relies on one breaks when you swap the other in.
- **Recursing on a deep graph.** A recursive DFS overflows the call stack on a long cycle. The Python versions here use an explicit stack.
- **Forgetting to reverse the graph in Kosaraju.** The second pass must run on the transpose, in reverse finish order.
- **Updating a low-link from a vertex that is no longer on the stack.** In Tarjan, an edge to a finished vertex in another component must be skipped.
</Callout>

## Frequently asked questions

<Faq>
  <FaqItem question="Which one should I learn first?">
    Kosaraju. Its two passes are easy to follow and to prove correct. Tarjan is the better tool once you know the idea, because it needs one pass and no reversed graph.
  </FaqItem>
  <FaqItem question="Do the two always return the same components?">
    Yes, the same sets of vertices. Only the order of the components and the order of the vertices inside each one differ.
  </FaqItem>
  <FaqItem question="How is this different from connected components?">
    Connected components ignore edge direction. In a directed graph two vertices can be connected one way only, and a strongly connected component needs a path in both directions.
  </FaqItem>
  <FaqItem question="How do SCCs help with 2-SAT?">
    Build a graph with an edge for each implication of the formula. If a variable and its negation end up in one component, they imply each other and no assignment works. Otherwise the order of the components gives an assignment.
  </FaqItem>
</Faq>
