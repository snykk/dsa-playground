## What this area covers

Geometry code is short, but it fails on edge cases: collinear points, duplicates, zero-length segments. The two sub-areas are built to handle those cases.

- **Basic Geometry** covers single objects and pairs. It holds the cross product, which says whether a path turns left, right or goes straight, and the tests built on it.
- **Advanced Geometry** covers a whole set of points. It finds the outline, the extent and the closest pair, and it calls the same cross product in the inner loop.

One rule runs through both. Comparisons are exact: the code tests signs and equalities directly and uses no epsilon. With integer coordinates this is exact in Python, and in C++ and Go while the products stay below 2^53.

## A path through the area

1. Read **Basic Geometry** first. Point, Line and Circle introduces `cross_product` and `orientation`, and Line Intersection applies them.
2. In **Advanced Geometry**, start with Convex Hull. It uses the cross product on every step.
3. Take Rotating Calipers next, because its input is a convex hull.
4. Finish with Closest Pair of Points, which is independent of the other two and uses divide and conquer.

## Frequently asked questions

<Faq>
  <FaqItem question="Why does exact arithmetic matter so much here?">
    A geometry algorithm makes many yes or no decisions, and one wrong decision can break the result: a hull that is not convex, or a segment test that misses a touching endpoint. A tolerance such as 1e-9 depends on the scale of the input, so it can be wrong for very small or very large shapes. Comparing exactly avoids this on integer input.
  </FaqItem>
  <FaqItem question="Do I need Basic Geometry before Advanced Geometry?">
    Yes, at least Point, Line and Circle. The hull, calipers and closest-pair code all use its distance and cross product.
  </FaqItem>
  <FaqItem question="What if I need many segment intersections at once?">
    Checking all pairs of n segments takes O(n^2). A sweep-line method such as Bentley-Ottmann reports them faster, but it is not part of this repository.
  </FaqItem>
</Faq>
