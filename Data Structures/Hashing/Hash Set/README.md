# Hash Set

A **Hash Set** is a data structure that stores unique elements using a hash table internally (only keys, no values).

---

## Overview

Hash Set uses a hash table internally but only stores keys without associated values. It provides fast average-case O(1) operations for add, remove, and contains.

---

## Operations

| Operation | Description | Time Complexity |
|-----------|-------------|----------------|
| **Add** | Add element to set | O(1) average |
| **Remove** | Remove element from set | O(1) average |
| **Contains** | Check if element exists | O(1) average |
