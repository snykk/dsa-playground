# Hash Set (Python)

A **Hash Set** is a data structure that stores unique elements using a hash table internally.

---

## Operations

### 1. Add

```python
set = HashSet()
set.add("apple")
set.add("banana")
```

**Time Complexity**: O(1) average

### 2. Remove

```python
set.remove("apple")
```

**Time Complexity**: O(1) average

### 3. Contains

```python
if "apple" in set:
    print("Found!")
```

**Time Complexity**: O(1) average

---

## Related Data Structures

- **Hash Table**: Stores key-value pairs
- **Hash Map**: Extended hash table
