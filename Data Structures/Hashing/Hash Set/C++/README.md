# Hash Set (C++)

A **Hash Set** stores unique elements using a hash table.

---

## Operations

- `add(key)`: Add element
- `remove(key)`: Remove element
- `contains(key)`: Check existence

---

## Compilation

```bash
g++ -std=c++11 hash_set.cpp hash_set_test.cpp -o hash_set_test
./hash_set_test
```
