# Python Implementation

This folder contains **basic string operations implemented in Python**:

- `access_char(s, index)`: access a single character
- `string_length(s)`: get the length of a string
- `traverse_string(s)`: iterate over characters
- `concatenate(s1, s2)`: join two strings
- `substring(s, start, end)`: get a substring

Run tests with:

```bash
python -m unittest introduction_test.py
```
