# 📚 Introduction to Strings

Strings are **linear sequences of characters**, one of the most fundamental data types in programming.

### Purpose

- Learn **basic string operations**.
- Understand strings as a **linear data structure**.
- Prepare for **string manipulation and pattern matching** problems.

### Key Operations

- Access individual characters
- String length
- Traversal
- Concatenation
- Substring / slicing

### Complexity Table

| Operation     | Complexity |
| ------------- | ---------- |
| Access        | O(1)       |
| Length        | O(1)       |
| Traversal     | O(n)       |
| Concatenation | O(n+m)     |
| Substring     | O(k)       |

### Learning Tip

Focus on **understanding strings as a sequence of characters**, similar to arrays.  
This foundational knowledge will make manipulation and pattern matching much easier.
