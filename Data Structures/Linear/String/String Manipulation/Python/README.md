# Python Implementation

This folder contains **common string manipulation functions** in Python.

#### Operations Implemented

- `reverse_string(s)`
- `is_palindrome(s)`
- `count_vowels(s)`
- `replace_char(s, old, new)`
- `to_upper(s)`
- `to_lower(s)`
- `split_string(s, sep)`
- `join_string(lst, sep)`

Run tests:

```bash
python -m unittest string_manipulation_test.py
```
