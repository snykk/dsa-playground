# 📚 String Manipulation

String manipulation is essential for solving **text-based problems** in interviews and competitive programming.

### Key Operations

- Reverse string
- Palindrome check
- Count vowels
- Replace characters
- Convert case (upper/lower)
- Split & join strings

### Complexity

| Operation       | Complexity |
| --------------- | ---------- |
| Reverse         | O(n)       |
| Palindrome      | O(n)       |
| Count vowels    | O(n)       |
| Replace         | O(n)       |
| Case conversion | O(n)       |
| Split & Join    | O(n)       |

### Learning Tips

- Strings are **immutable in Python and Go**, so many operations create new strings.
- Understanding **traversal and indexing** is crucial.
- Many string problems reduce to **array-like manipulations**.
