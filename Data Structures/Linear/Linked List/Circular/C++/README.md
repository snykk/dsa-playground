# Circular Linked List - C++

This folder contains a **C++ implementation** of a **Singly Circular Linked List**.

## Features

- Insert at head
- Insert at tail
- Delete a node by value
- Traverse nodes safely with optional limit to prevent infinite loops

## Compilation & Running Tests

```bash
g++ circular_linked_list.cpp circular_linked_list_test.cpp -o test_cll
./test_cll
```
