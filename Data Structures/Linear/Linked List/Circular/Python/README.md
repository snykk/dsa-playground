# Circular Linked List - Python

This folder contains the Python implementation of a **Circular Linked List**.  
Circular Linked List is a variation of linked list where the last node points back to the head, forming a loop.

## Features:

- Insert at head
- Insert at tail
- Delete a node by value
- Traverse with limit to avoid infinite loops

## Unit Tests

Run tests with:

```bash
python -m unittest circular_linked_list_test.py
```
