# Circular Linked List

Circular Linked List is a variation of a linked list where the last node points back to the head, forming a loop.  
This structure is useful for applications requiring a circular traversal or repeated iteration over elements without restarting from scratch.

## Features Implemented

- Singly circular linked list
- Insert at head
- Insert at tail
- Delete node by value
- Traverse safely (with optional limit to avoid infinite loops)

## Language Implementations

- Python
- C++
- Go
