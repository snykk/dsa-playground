# 🚀 Singly Linked List - Go

This folder contains a Go implementation of **Singly Linked List** with unit tests.

**Files:**

- `main.go` → Core implementation
- `main_test.go` → Unit tests using Go's `testing` package

**How to run:**

```bash
go run main.go
```

**How to test:**

```bash
go test
```

**Key Operation**

- Insert at head
- Insert at tail
- Delete by value
- Display / traverse elements
