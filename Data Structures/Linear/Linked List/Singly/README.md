# 🧩 Singly Linked List

Singly Linked List is a linear, dynamic data structure where each node contains:

- `data`
- `next` pointer to the next node

**Characteristics:**

- One-directional traversal
- Dynamic memory allocation
- Efficient insertion/deletion at head

**Common Operations:**

1. Insert at head/tail
2. Delete by value
3. Search for element
4. Traverse and display elements

**Time Complexity:**
| Operation | Complexity |
|-----------------|------------|
| Insert at head | O(1) |
| Insert at tail | O(n) |
| Delete node | O(n) |
| Search element | O(n) |
