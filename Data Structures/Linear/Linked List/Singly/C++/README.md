# ⚡ Singly Linked List - C++

This folder contains a C++ implementation of **Singly Linked List** with test file.

**Files:**

- `singly_linked_list.cpp` → Core implementation
- `singly_linked_list_test.cpp` → Test examples using `assert` and `main`

**How to compile and run:**

```bash
g++ singly_linked_list_test.cpp -o test
./test
```

**Key Operation**

- Insert at head
- Insert at tail
- Delete by value
- Display / traverse elements
