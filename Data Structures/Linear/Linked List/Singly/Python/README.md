# 🐍 Singly Linked List - Python

This folder contains a Python implementation of **Singly Linked List** with unit tests.

**Files:**

- `singly_linked_list.py` → Core implementation
- `singly_linked_list_test.py` → Unit tests using `unittest`

**How to run:**

```bash
python -m unittest singly_linked_list_test.py
```

**Key Operation**

- Insert at head
- Insert at tail
- Delete by value
- Display / traverse elements
