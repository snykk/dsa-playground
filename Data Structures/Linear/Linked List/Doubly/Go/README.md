# 🚀 Doubly Linked List - Go

This folder contains a Go implementation of **Doubly Linked List** with unit tests.

**Files:**

- `main.go` → Core implementation
- `main_test.go` → Unit tests using `testing` package

**Run the program:**

```bash
go run main.go
```

**Run the tests:**

```bash
go test
```

**Key Operations**

- Insert at head
- Insert at tail
- Delete by value
- Traverse forward
- Traverse backward
- vSearch element
