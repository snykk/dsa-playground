# ⚡ Doubly Linked List - C++

This folder contains a C++ implementation of **Doubly Linked List** with test file.

**Files:**

- `doubly_linked_list.cpp` → Core implementation
- `doubly_linked_list_test.cpp` → Test examples

**Compile and run:**

```bash
g++ doubly_linked_list_test.cpp -o test
./test
```

**Key Operations**

- Insert at head
- Insert at tail
- Delete by value
- Traverse forward
- Traverse backward
- vSearch element
