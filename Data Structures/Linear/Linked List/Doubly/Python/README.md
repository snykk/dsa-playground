# 🐍 Doubly Linked List - Python

This folder contains a Python implementation of **Doubly Linked List** with unit tests.

**Files:**

- `doubly_linked_list.py` → Core implementation
- `doubly_linked_list_test.py` → Unit tests using `unittest`

**How to run tests:**

```bash
python3 doubly_linked_list_test.py
```

**Key Operations**

- Insert at head
- Insert at tail
- Delete by value
- Traverse forward
- Traverse backward
- vSearch element
