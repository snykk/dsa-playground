# Queue

A First-In-First-Out (FIFO) data structure.

## Operations

| Operation | Time Complexity |
|-----------|-----------------|
| Enqueue | O(1) |
| Dequeue | O(1) |
| Front/Peek | O(1) |
| isEmpty | O(1) |

## Implementations

- Array-based (circular)
- Linked list-based
- Double-ended queue (Deque)

## Variants

- **Priority Queue**: Elements with priorities
- **Circular Queue**: Efficient array utilization
- **Deque**: Insert/remove from both ends

## Applications

- BFS traversal
- Task scheduling
- Buffer management
- Print queue
