# Templates

Competitive programming boilerplate templates for quick problem-solving setup.

## Available Templates

| Language | Description |
|----------|-------------|
| [C++ Boilerplate](Cpp_Boilerplate/) | Complete C++ template with macros, utilities, and data structures |
| [Python Boilerplate](Python_Boilerplate/) | Python template with fast I/O and common utilities |
| [Go Boilerplate](Go_Boilerplate/) | Go template for competitive programming |

## Features

### C++ Boilerplate
- Type definitions (ll, vi, pii, etc.)
- Useful macros (pb, mp, all, rep)
- Math utilities (gcd, lcm, power, modInverse)
- Data structures (DSU, SegTree)
- Graph utilities (BFS, DFS)

### Python Boilerplate
- Fast I/O (sys.stdin.readline)
- Combinatorics class
- Union-Find, Segment Tree
- Binary search utilities

### Go Boilerplate
- Buffered I/O
- Math utilities
- Data structures (DSU, SegTree, Graph)

## Usage

Copy the template to your solution file and modify the `solve()` function.

```cpp
// C++ example
void solve() {
    int n;
    cin >> n;
    // Your solution here
}
```

```python
# Python example
def solve():
    n = inp()
    # Your solution here
```

```go
// Go example
func solve() {
    n := readInt()
    // Your solution here
}
```
