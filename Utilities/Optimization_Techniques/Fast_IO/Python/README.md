# Fast I/O (Python)

Python implementation of fast input/output techniques.

## Functions

### Basic Fast I/O
- `fast_input()` - Fast single line input
- `fast_int()` - Fast single integer
- `fast_ints()` - Fast list of integers
- `fast_floats()` - Fast list of floats
- `fast_strings()` - Fast list of strings

### Fast Output
- `fast_print(*args)` - Fast print
- `fast_print_list(lst)` - Fast print for lists
- `fast_print_matrix(matrix)` - Fast print for matrices

### Buffered I/O
- `BufferedInput` - For very large inputs
- `BufferedOutput` - For very large outputs

## Usage

```python
n = fast_int()
arr = fast_ints()
fast_print(sum(arr))
```
