# Precomputation (Python)

Python implementation of precomputation techniques.

## Features

- Factorials and inverse factorials
- Prime sieve
- Smallest Prime Factor (SPF)
- Prefix sums (1D and 2D)
- Sparse table (RMQ)
- LCA precomputation

## Usage

```python
fact = Factorials(1000)
print(fact.nCr(10, 3))

primes, is_prime = sieve(100)
ps = PrefixSum(arr)
sum = ps.query(l, r)
```
