# Precomputation (C++)

C++ implementation of precomputation techniques.

## Features

- Factorials and inverse factorials
- Prime sieve
- Smallest Prime Factor (SPF)
- Prefix sums (1D and 2D)
- Sparse table (RMQ)
- LCA precomputation

## Usage

```cpp
precomputeFactorials();
cout << nCr(10, 3) << endl;

vector<int> primes = sieve(100);
PrefixSum ps(arr);
int sum = ps.query(l, r);
```
