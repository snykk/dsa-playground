## Problem-Solving Tips

### Interactive Problems
1. Always flush output after queries
2. Use `endl` or `cout.flush()` in C++
3. Handle invalid responses gracefully

### Constructive Problems
1. Check if solution exists first
2. Build incrementally
3. Verify constraints during construction

### Game Theory
1. Identify if game is impartial
2. Look for Nim-like structure
3. Calculate small cases to find pattern
4. Use DP for complex state spaces
