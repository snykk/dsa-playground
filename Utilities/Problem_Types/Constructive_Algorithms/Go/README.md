# Constructive Algorithms (Go)

Go implementation of constructive algorithm patterns.

## Functions

- `ConstructPermutation(n, k)` - Build permutation with k differences
- `ConstructArrayWithSum(n, total, min, max)` - Build array with constraints
- `ConstructGraph(degrees)` - Build graph with degree sequence

## Usage

```go
perm := ConstructPermutation(5, 2)
arr := ConstructArrayWithSum(5, 20, 1, 5)
```
