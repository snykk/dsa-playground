# Constructive Algorithms (Python)

Python implementation of constructive algorithm patterns.

## Functions

- `construct_permutation(n, k)` - Build permutation with k differences
- `construct_array_with_sum(n, total, min, max)` - Build array with constraints
- `construct_graph(degrees)` - Build graph with degree sequence
- `construct_string(n, a, b)` - Build string with character counts

## Usage

```python
perm = construct_permutation(5, 2)
arr = construct_array_with_sum(5, 20, 1, 5)
```
