# Constructive Algorithms (C++)

C++ implementation of constructive algorithm patterns.

## Functions

- `constructPermutation(n, k)` - Build permutation with k differences
- `constructArrayWithSum(n, sum, min, max)` - Build array with constraints
- `constructGraph(degrees)` - Build graph with degree sequence
- `constructString(n, a, b)` - Build string with character counts

## Usage

```cpp
vector<int> perm = constructPermutation(5, 2);
vector<int> arr = constructArrayWithSum(5, 20, 1, 5);
```
