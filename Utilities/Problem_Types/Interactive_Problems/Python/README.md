# Interactive Problems (Python)

Python implementation for interactive competitive programming problems.

## Key Points

- Always flush output after queries
- Use `flush=True` in print statements
- Handle responses carefully

## Functions

- `query(x)` - Send query and get response
- `query_multi(*args)` - Query with multiple arguments
- `answer(x)` - Submit final answer
- `answer_multi(*args)` - Submit answer with multiple values
- `guess_number(n)` - Binary search to guess number
- `binary_search_answer(n, predicate)` - Generic binary search

## Usage

```python
response = query(42)
answer(result)
```
