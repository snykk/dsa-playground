# Game Theory (Python)

Python implementation of game theory algorithms.

## Functions

- `nim_winner(piles)` - Check if first player wins in Nim
- `nim_winning_move(piles)` - Find winning move
- `mex(s)` - Minimum excludant
- `subtraction_grundy(n, moves)` - Calculate Grundy numbers
- `combined_grundy(states, tables)` - Combined game
- `misere_nim_winner(piles)` - Misère Nim

## Usage

```python
piles = [3, 4, 5]
winner = nim_winner(piles)
```
