# Prefix Sum / Difference Array Pattern - Python

This folder contains Python implementations of the **Prefix Sum / Difference Array** pattern.

---

## Overview

Efficient techniques for range queries and updates using prefix sums and difference arrays.

---

## Implemented Classes

### `PrefixSum`
Prefix sum array for O(1) range sum queries.

### `DifferenceArray`
Difference array for O(1) range updates.
