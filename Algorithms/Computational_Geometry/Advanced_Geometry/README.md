# Advanced Geometry

Advanced geometric algorithms for computational geometry.

## Topics

| Algorithm | Description |
|-----------|-------------|
| [Convex Hull](Convex_Hull/) | Finding convex hull of points |
| [Closest Pair of Points](Closest_Pair_of_Points/) | Finding nearest point pair |
| [Rotating Calipers](Rotating_Calipers/) | Diameter and width of point set |

## Complexity

| Algorithm | Time | Space |
|-----------|------|-------|
| Convex Hull (Graham) | O(n log n) | O(n) |
| Convex Hull (Jarvis) | O(nh) | O(h) |
| Closest Pair | O(n log n) | O(n) |
| Rotating Calipers | O(n) | O(1) |

## Applications

- Collision detection
- Path planning
- Geographic information systems
- Computer graphics
