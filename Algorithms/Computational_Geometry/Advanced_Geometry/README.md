# Advanced Geometry

Advanced geometric algorithms for computational geometry.

## Topics

| Algorithm | Description |
|-----------|-------------|
| [Convex Hull](Convex%20Hull/) | Finding convex hull of points |
| [Closest Pair of Points](../../Divide_and_Conquer/Closest%20Pair%20of%20Points/) | Finding nearest point pair |
| [Rotating Calipers](Rotating%20Calipers/) | Diameter and width of point set |

## Complexity

| Algorithm | Time | Space |
|-----------|------|-------|
| Convex Hull (Graham) | O(n log n) | O(n) |
| Convex Hull (Jarvis) | O(nh) | O(h) |
| Closest Pair | O(n log n) | O(n) |
| Rotating Calipers | O(n) | O(1) |

## Applications

- Collision detection
- Path planning
- Geographic information systems
- Computer graphics
