# Advanced String Algorithms

Advanced algorithms for string processing and analysis.

## Topics

| Algorithm | Description |
|-----------|-------------|
| [Z-Algorithm](Z-Algorithm/) | Z-array for pattern matching |
| [Suffix Array](Suffix%20Array/) | Sorted array of all suffixes |
| [Longest Common Substring](Longest%20Common%20Substring/) | Finding common substrings |
| [Longest Palindromic Substring](Longest%20Palindromic%20Substring%20(Manacher's)/) | Manacher's algorithm |

## Complexity

| Algorithm | Time | Space |
|-----------|------|-------|
| Z-Algorithm | O(n) | O(n) |
| Suffix Array | O(n log n) | O(n) |
| Suffix Array + LCP | O(n log n) | O(n) |
| Manacher's | O(n) | O(n) |

## Applications

- **Z-Algorithm**: Pattern matching, string comparison
- **Suffix Array**: Substring search, LCP queries
- **LCS**: DNA sequence alignment, diff tools
- **Manacher's**: Finding palindromes efficiently
