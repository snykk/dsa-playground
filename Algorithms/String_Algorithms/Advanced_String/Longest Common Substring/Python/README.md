# Longest Common Substring (Python)

Finds the longest common substring between two strings using dynamic programming.

**Time Complexity:** O(m × n)  
**Space Complexity:** O(m × n)

---

## Usage

```python
from longest_common_substring import longest_common_substring
substring, length, idx1, idx2 = longest_common_substring(s1, s2)
```
