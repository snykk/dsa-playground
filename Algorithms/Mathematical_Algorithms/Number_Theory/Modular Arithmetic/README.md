# Modular Arithmetic

Operations under modulo for handling large numbers.

## Key Operations

- Addition: (a + b) mod m
- Subtraction: (a - b + m) mod m
- Multiplication: (a * b) mod m
- Division: a * b⁻¹ mod m

## Modular Inverse

- **Fermat's Little Theorem**: a⁻¹ ≡ a^(p-2) mod p
- **Extended GCD**: ax + my = gcd(a, m)

## Key Theorems

- **Fermat's Little Theorem**: a^(p-1) ≡ 1 mod p
- **Euler's Theorem**: a^φ(n) ≡ 1 mod n
- **Chinese Remainder Theorem**: Solving simultaneous congruences

## Applications

- Cryptography
- Competitive programming
- Hash functions
