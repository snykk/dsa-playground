# Fibonacci Numbers

**Fibonacci Numbers** are a classic example of Dynamic Programming.

---

## Overview

F(n) = F(n-1) + F(n-2) with F(0) = 0, F(1) = 1.

---

## Implementations

- **Naive**: O(2^n) - recursive
- **Memoization**: O(n) - top-down DP
- **Tabulation**: O(n) - bottom-up DP
- **Optimized**: O(n) time, O(1) space
- **Matrix**: O(log n) - advanced

---

## Complexity

| Approach | Time | Space |
|----------|------|-------|
| **Naive** | O(2^n) | O(n) |
| **DP** | O(n) | O(n) |
| **Optimized** | O(n) | O(1) |
| **Matrix** | O(log n) | O(log n) recursion stack |
