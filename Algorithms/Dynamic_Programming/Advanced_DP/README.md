# Advanced Dynamic Programming

Advanced DP techniques for complex problems.

---

## Categories

1. **DP on Trees**: Tree-structured DP
2. **DP on Graphs**: Graph DP (DAG, etc.)
3. **Bitmask DP**: State compression with bits
4. **Digit DP**: Number theory DP

---

## Complexity

Varies by problem type, typically exponential in some parameter.
