# Bucket Sort (Go)

**Bucket Sort** distributes elements into buckets and sorts each bucket.

---

## Usage

```go
arr := []float64{0.897, 0.565, 0.656, 0.1234, 0.665, 0.3434}
BucketSort(arr)
```

---

## Testing

```bash
go test
```

---

## Complexity

- **Time**: O(n + k) average, O(n²) worst
- **Space**: O(n)
