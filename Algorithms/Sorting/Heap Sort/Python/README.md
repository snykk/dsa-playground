# Heap Sort (Python)

**Heap Sort** is a comparison-based sorting algorithm that uses a binary heap.

---

## Complexity

- **Time**: O(n log n)
- **Space**: O(1)

---

## Usage

```python
from heap_sort import heap_sort

arr = [64, 34, 25, 12, 22, 11, 90]
sorted_arr = heap_sort(arr.copy())
```
