# Kruskal's Algorithm

**Kruskal's Algorithm** finds Minimum Spanning Tree using Union-Find.

---

## Algorithm

1. Sort edges by weight
2. Add edges greedily (avoiding cycles)
3. Stop when V-1 edges added

---

## Complexity

- **Time**: O(E log E)
- **Space**: O(V)

---
