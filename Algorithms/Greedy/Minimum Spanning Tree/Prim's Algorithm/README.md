# Prim's Algorithm

**Prim's Algorithm** finds MST by growing tree from a vertex.

---

## Algorithm

1. Start with any vertex
2. Add minimum edge to unvisited vertex
3. Repeat until all vertices included

---

## Complexity

- **Time**: O(E log V) with heap
- **Space**: O(V)

---

- **Python** (`Python/`) - Complete with multiple representations
- **C++** (`C++/`) - Complete (lazy Prim, binary heap)
