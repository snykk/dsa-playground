# Fractional Knapsack

**Fractional Knapsack** maximizes value in a knapsack by allowing fractions of items.

---

## Algorithm

1. Sort by value/weight ratio
2. Take items greedily
3. Take fraction of last item if needed

---

## Complexity

- **Time**: O(n log n)
- **Space**: O(n)
