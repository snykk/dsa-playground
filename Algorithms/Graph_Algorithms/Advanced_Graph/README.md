# Advanced Graph Algorithms

Advanced algorithms for complex graph problems.

## Topics

| Algorithm | Description |
|-----------|-------------|
| [Topological Sort](Topological%20Sort/) | Linear ordering of DAG vertices |
| [Strongly Connected Components](Strongly%20Connected%20Components/) | Kosaraju's/Tarjan's algorithm |
| [Articulation Points and Bridges](Articulation%20Points%20and%20Bridges/) | Critical nodes and edges |
| [Eulerian Path](Eulerian%20Path/) | Path visiting every edge once |
| [Hamiltonian Path](Hamiltonian%20Path/) | Path visiting every vertex once |

## Complexity

| Algorithm | Time | Space |
|-----------|------|-------|
| Topological Sort | O(V + E) | O(V) |
| SCC (Kosaraju/Tarjan) | O(V + E) | O(V) |
| Articulation Points | O(V + E) | O(V) |
| Bridges | O(V + E) | O(V) |

## Applications

- **Topological Sort**: Task scheduling, dependency resolution
- **SCC**: Analyzing strongly connected regions
- **Articulation Points**: Network reliability
- **Bridges**: Finding critical connections
