# Amortized Analysis (C++)

**Amortized Analysis** provides the average performance of each operation over a sequence of operations.

---

## Usage

```bash
g++ -std=c++11 -o amortized_analysis amortized_analysis.cpp
./amortized_analysis
```

---

## Key Points

- **Average performance**: Considers sequences of operations
- **Expensive operations**: Paid for by cheap ones
- **Common examples**: Dynamic arrays, binary counters
