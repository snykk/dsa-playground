# Big-Omega (Ω) Notation (C++)

**Big-Omega (Ω) Notation** describes the lower bound of an algorithm's time complexity.

---

## Usage

```bash
g++ -std=c++11 -o big_omega big_omega.cpp
./big_omega
```

---

## Key Points

- **Lower Bound**: Describes the best-case scenario
- **Minimum Performance**: Guarantees algorithm won't be faster than this
