# Big-Theta (Θ) Notation (Go)

**Big-Theta (Θ) Notation** describes a tight bound on an algorithm's time complexity.

---

## Usage

```bash
go run main.go
go test
```

---

## Key Points

- **Tight Bound**: Both upper and lower bounds are the same
- **All Cases**: Best, average, and worst cases have the same complexity
