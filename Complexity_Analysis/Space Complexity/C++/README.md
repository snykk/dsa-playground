# Space Complexity (C++)

**Space Complexity** measures the amount of memory space an algorithm uses.

---

## Usage

```bash
g++ -std=c++11 -o space_complexity space_complexity.cpp
./space_complexity
```

---

## Key Points

- **Auxiliary space**: Extra space used by the algorithm
- **In-place**: O(1) space algorithms
- **Trade-offs**: Space vs time complexity
